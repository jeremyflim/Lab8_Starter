# Lab8-Starter

Deployed URL: https://jeremyflim.github.io/Lab8_Starter/

Graceful degradation and service workers are related because service workers let a web app keep useful functionality even when the network is slow or unavailable. The app can start with the full online experience, then degrade gracefully by using cached HTML, CSS, JavaScript, images, and recipe data from the browser when the network fails.
